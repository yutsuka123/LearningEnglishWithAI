# クロスワード(猫のマスの英単語クロスワード)ストーリーボード

- ファイル名: `crossword`(`static/video/crossword.mp4` / `static/video/posters/crossword.jpg`)
- 尺: 19.6秒 / 縦9:16(720x1280)/ 30fps / H.264 High + AAC(モノラル)
- 視点: **未登録ゲスト**・ダークテーマ・文字サイズ既定
- 台本のコード: `scripts/videos/scenarios/crossword.py`

## ゲストの導線(実アプリで確認)

- ゲームタブ(誰でも表示)→「🧩 サンプルクロスワード」→ サンプル一覧。ゲストは「ゲストとして遊べます
  (残り5/5個)」で、**21個中5個だけ**遊べる(残り16個は「🔒 登録した方のみ」)。
  遊べる5個: はじめてのクロスワード / どうぶつ大集合 / 料理の英語 / ネコ好きの中級 / 天文。
- ゲームメニュー(「クロスワード作成 🔒 要登録+課金」)とサンプル一覧(🔒付きカード)は **映さない**。
  撮影前(prepare)にサンプルの盤面まで進め、動画は盤面から始める。
- 題材: **「どうぶつ大集合クロスワード」**(サンプルのDBは content.db の `crossword_samples`。
  盤面の全8語がゲスト無料範囲内・音声保存済みであることを撮影前に確認)。
  クリュー1(タテ・6文字)=RABBIT、ヒント文「The ______ hopped across the lawn.」。
  盤面の「未解答マスを猫にする」はサンプルの既定オン(猫のマス)。

## 字幕全文(事実の裏付け)

| 字幕 | 裏付け |
|---|---|
| 猫のマスを埋める英単語クロスワード | サンプルは「未解答マスを猫にする」が既定オン(views.js `cwCatPrefGet(true, "block")`) |
| 例文のヒントから単語を当てる | クリューの「英語ヒント」=穴埋め例文(`english_style: fill_blank`) |
| 発音のヒントも聞ける(AIの自然な英語音声) | ヒント「🔊 発音を聞く」(男声で再生)。表記は「AIの自然な英語音声」 |
| 英単語を入力して「答える」 | 入力欄「英単語を入力」+「答える」 |
| 正解するとマスが埋まり発音も聞ける | 正解後、マスに文字が入り、カードに音声ボタン(男/女)と詳細ボタンが出る |
| 登録なしで、いますぐ試せます / サンプルのクロスワードはゲストでも遊べます | サンプル一覧の「ゲストとして遊べます(残り5/5個)」。**遊べるのは一部のサンプルだけ**なので「サンプルのクロスワードは」と限定した(全部とは書かない) |

## 撮影上の処理(アプリ本体は無変更)

- 共通の隠し要素(残り0pt・ⓘ・AI未設定・バージョン・文字サイズ・入力モード・メンテナンス予告)に加えて、
  **「🔓 全部答えを見る」「🔓 答えを見る」を撮影側で隠した**(小さいと錠前(🔒)に見えて紛らわしいため)。
  トーストは「正解！」を映すため隠さない(ゲスト向けの「学習の記録は保存されていません」は
  study系タブ5クリック目に出る仕様で、ゲームタブでは出ない)。
- 盤面がページ最下部に近く、そのままでは盤面を画面の上端に出せず、上に前のカードの端(「ギブアップ」の断片)
  が写り込むため、撮影側で盤面の下に余白(320px)を足した(`EXTRA_CSS`)。
