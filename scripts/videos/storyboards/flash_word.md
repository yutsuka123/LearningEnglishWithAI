# フラッシュ単語 ストーリーボード

- ファイル名: `flash_word`(`static/video/flash_word.mp4` / `static/video/posters/flash_word.jpg`)
- 尺: 19.6秒 / 縦9:16(720x1280)/ 30fps / H.264 High + AAC(モノラル)
- 視点: **未登録ゲスト**・ダークテーマ・文字サイズ既定
- 台本のコード: `scripts/videos/scenarios/flash_word.py`

## ゲストの導線(実アプリで確認)と、動画にした範囲

1. 「フラッシュ単語」タブ → 設定パネル(方向・カテゴリ・分野・レベル×2・覚えた・枚数・速度・声・自動再生・
   無料のみ の約10個)。**既定値のまま**でよい(ゲストは「無料のみ」の選択が後で出る)。
2. 「▶ 開始」(モバイルではパネルの一番下・スクロールが必要)→ ポップアップ「🔊 出題範囲を選択」
   →「🔊 無料で聴ける単語のみ」→ カード。**設定を触る様子は映さず**、prepare で開始まで進め、
   動画はカードの表示から始める(ポップアップの本文に🔒の文字が入るため、ポップアップ自体も映さない)。
3. カード: 出題キューは**アプリが実際に取得したもの**(`/api/words/quiz?free_range_only=true`)の先頭から
   使う: actually → additional → advance(いずれもゲスト無料範囲内・🆓・単語/例文の男女音声あり)。
   撮影前に先頭3枚が「ゲスト無料範囲・単語と例文の音声が8KB以上」であることを確認し、満たさなければ失敗する。

| 4.1〜6.4 | カード中央にタップ表示 → 4.59秒にタップ → 答えが表示(実際に・本当は/発音記号/例文/例文訳) | タップで / **意味と例文**を確認 | |

## 字幕全文(事実の裏付け)

| 字幕 | 裏付け |
|---|---|
| 単語カードを次々にめくって覚える | フラッシュ単語の説明「単語カードを次々にめくって答え合わせする高速学習モード」 |
| タップで意味と例文を確認 | 「カードをタップで答え」。答え面に意味・発音記号・例文・例文訳が出る |
| 例文の音声も聞ける(AIの自然な英語音声) | 「🔊 例文」ボタン。表記は「AIの自然な英語音声」(「ネイティブ音声」とは書かない) |
| スワイプで採点 ⬆覚えた ➡うろ覚え ⬇できない | 画面の凡例「⬆ 覚えた ・ ⬇ できない ・ ➡ うろ覚え ・ ⬅ 戻る／カードをタップで答え」 |
| 登録なしで、いますぐ試せます / 閲覧と一部の音声は無料 | ようこそ画面の文言と同じ |

## 撮影上の処理(アプリ本体は無変更)

- 共通の隠し要素(残り0pt・ⓘ・AI未設定・バージョン・文字サイズ・入力モード・メンテナンス予告・トースト)。
  トースト(ゲスト向けの「学習の記録は保存されていません」等)は隠している。ゲストの採点API
  (`known`/`vague`)は200を返すことを確認済み(記録失敗のトーストは出ない)。
- スワイプはChromiumのタッチイベント(CDP `Input.dispatchTouchEvent`)で実際に指を動かして行う。
  指の位置は白い半透明の円で表示(撮影側のオーバーレイ)。
